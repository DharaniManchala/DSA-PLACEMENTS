WHAT IS MONOTONIC STACK?
------------------------

Monotonic Stack means:
stack maintains elements in sorted order.

Two Types:
1. Monotonic Increasing Stack
2. Monotonic Decreasing Stack


========================================================
1. MONOTONIC INCREASING STACK
========================================================

Maintains:
small → big

Example:
[1,2,3,5]

While pushing:
remove bigger elements.

Condition:
while stack and stack[-1] > current:
    stack.pop()


USED FOR:
----------
1. Next Smaller Element
2. Previous Smaller Element
3. Sum of Subarray Minimums
4. Largest Rectangle Histogram
5. Maximal Rectangle


KEY THINKING:
--------------
Current element wants smaller relation.


========================================================
2. MONOTONIC DECREASING STACK
========================================================

Maintains:
big → small

Example:
[9,7,5,2]

While pushing:
remove smaller elements.

Condition:
while stack and stack[-1] < current:
    stack.pop()


USED FOR:
----------
1. Next Greater Element
2. Previous Greater Element
3. Daily Temperatures
4. Stock Span
5. Sum of Subarray Maximums


KEY THINKING:
--------------
Current element wants greater relation.

========================================================
TECHNIQUE 1 — NEXT GREATER ELEMENT
========================================================

QUESTION TYPE:
---------------
Find first greater element on RIGHT.

STACK TYPE:
-------------
Monotonic Decreasing Stack

TRAVERSAL:
------------
LEFT → RIGHT

LOGIC:
--------
Current element resolves smaller elements.

CONDITION:
------------
while stack and nums[stack[-1]] < nums[i]:
    answer[stack.pop()] = nums[i]

PROBLEMS:
-----------
1. Next Greater Element I
2. Daily Temperatures
3. Next Greater Element II

========================================================
TECHNIQUE 5 — CONTRIBUTION TECHNIQUE
========================================================

USED IN:
---------
1. Sum of Subarray Minimums
2. Sum of Subarray Maximums
3. Sum of Subarray Ranges

MAIN IDEA:
------------
Instead of finding answer for each subarray,
find contribution of each element.

FORMULA:
----------
arr[i] * left * right

WHERE:
-------
left  = choices on left
right = choices on right

NEED:
------
1. Previous Smaller
2. Next Smaller

OR

1. Previous Greater
2. Next Greater


========================================================
TECHNIQUE 6 — HISTOGRAM TECHNIQUE
========================================================

USED IN:
---------
1. Largest Rectangle Histogram
2. Maximal Rectangle

MAIN IDEA:
------------
Find width where current bar can expand.

NEED:
------
1. Previous Smaller
2. Next Smaller

FORMULA:
----------
width = right - left - 1

area = height * width


========================================================
TECHNIQUE 7 — CIRCULAR ARRAY MONOTONIC STACK
========================================================

USED IN:
---------
1. Next Greater Element II

MAIN IDEA:
------------
Traverse array twice.

LOOP:
-------
for i in range(2*n):

ACCESS:
---------
